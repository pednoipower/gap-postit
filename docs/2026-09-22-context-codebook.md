# Context codebook — for coding the เพราะเมื่อ [สถานการณ์/เงื่อนไข] blank

Participants describe the situation in their own words (*where · when · what
is going on*). Context is classified **afterwards**, by the analyst, with this
codebook. The AI first-pass prompt on the control panel uses the same codes;
two human coders check a sample and resolve disagreements before anything is
reported.

Each chain gets **one primary code** (the feature that most directly conditions
the response) and any number of secondary codes.

| Code | Thai cue words in participants' text | Realist level (Pawson's 4 I's) | Programme can… |
|---|---|---|---|
| **WORKLOAD / TIME** | คนล้น, คิวยาว, 5 นาทีต่อราย, วันพุธ, นอกเวลา, ดึก, เวร, ไม่มีเวลา | institutional | change (protect time, shift tasks) |
| **PLACE / STRUCTURE** | คนละตึก, คนละชั้น, OPD/IPD, ไม่มีห้อง, ห่างไกล, รพ.ชุมชน | institutional–infrastructural | partly change (co-locate, joint round) |
| **POLICY / KPI / MONEY** | ตัวชี้วัด, นับจำนวน, เบิกไม่ได้, สปสช., นโยบาย, ผู้บริหาร | infrastructural | change slowly, or work around |
| **INFORMATION / RECORD** | ไม่มีช่อง, HIS, EMR, แบบฟอร์ม, ไม่รู้ว่าเคยคุย, ไม่มี alert, กระดาษ | institutional | change (cheapest lever) |
| **TEAM RELATIONSHIP** | ไม่เคยเจอ, ไม่รู้จัก, ไม่กล้าโทร, ต่างฝ่ายต่าง, รอให้อีกทีม, หน้าที่ของอีกทีม | interpersonal | build (repeated contact, coordinator) |
| **PATIENT / FAMILY** | ครอบครัวอยากฟอก, มาครั้งเดียว, อำเภอไกล, ไม่เข้าใจการพยากรณ์, "ไม่รักษา", วัฒนธรรม | individual (patient side) / infrastructural (culture) | work with, not against (decision aid, wording) |
| **TEAM CAPACITY** | ไม่มั่นใจ, ไม่เคยทำ, ไม่รู้จะเริ่มยังไง, กลัวโดนร้องเรียน | individual (clinician side) | train |

## Rules

1. Code what the **participant** described, not what you infer. If the text
   says only *วันพุธ*, code WORKLOAD/TIME; do not add PLACE because you know
   the Wednesday clinic is far away.
2. The **เนื่องจาก** blank often names a second context (e.g. *เนื่องจากไม่มีช่องใน
   HIS*). Code it there as the *mechanism's missing resource*, and also as a
   secondary context code if it is a standing condition rather than a
   momentary reason.
3. **Works-here chains** get the same codes. The comparison you want is:
   same primary context code, same actor, different response — and what
   differs in the เพราะ.
4. A context that never co-occurs with a different response anywhere in the
   data is background, not context. Note it, but it does not enter a CMO.

## What to report

- Per gap: count of chains by primary code × team. A code raised by both teams
  across several settings and both Met and Unmet sites is a candidate
  demi-regularity; a code from one role in one setting is a local condition.
- For each candidate demi-regularity: the typical chain in participants' words,
  the actor, the response, and the works-here contrast if one exists.
- Sorted by the last column: which contexts the programme will change, build,
  work around, work with, or train for. That table is the bridge from the
  workshop to the programme design.
